## The joke

> My access badge still shows my 2019 photo. Security waves the photo in every morning — it's me they keep stopping.

## How it works

`main.ts` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`) and guards the competition gate:
1–200 characters, a single line, not only white space.
